## 1. 系统登录

### 1.1 访问系统

在浏览器中打开系统地址（由系统管理员提供），例如：

```
http://your-server-ip:5173
```

### 1.2 登录步骤

1. 在登录页面输入 **用户名** 和 **密码**
2. 点击 **「登录」** 按钮
3. 登录成功后自动跳转至首页

### 1.3 默认账号

| 用户名 | 密码 | 角色 | 说明 |
|--------|------|------|------|
| admin | admin123 | 超级管理员 | 首次登录后建议修改密码 |

### 1.4 忘记密码

请联系系统管理员重置密码。管理员可在 **「系统管理 > 用户管理」** 中找到对应用户，点击 **「重置密码」** 按钮。

### 1.5 安全提示

- 🔒 首次登录后请立即修改默认密码
- 🔒 密码建议包含大小写字母、数字和特殊字符
- 🔒 长时间不操作系统会自动退出登录
- 🔒 请勿将账号密码告知他人

## 3. 文档解析操作指南

### 3.1 功能概述

文档解析模块支持上传各类文档文件（PDF、DOCX、TXT），系统自动进行内容提取、结构化处理和向量索引生成，为后续的智能检索和类案推送提供数据基础。

### 3.2 上传文档

1. 进入 **「文档解析」** 菜单
2. 点击 **「上传文档」** 按钮
3. 在弹出的对话框中：
   - **选择文件** — 点击或拖拽文件至上传区域
   - **选择文档类型** — 指定文档所属分类
   - **选择密级** — 设置文档的保密级别
4. 点击 **「确认上传」**

### 3.3 查看解析进度

上传后可在 **「解析任务」** 列表中查看：

| 状态 | 说明 | 操作 |
|------|------|------|
| ⏳ 待处理 | 已上传，等待解析 | 无需操作 |
| 🔄 处理中 | 正在解析，显示进度条 | 可查看详情 |
| ✅ 已完成 | 解析完成，可查看结果 | 查看结果/删除 |
| ❌ 失败 | 解析出错 | 查看错误信息/重新上传 |

### 3.4 查看解析结果

解析完成后，点击文档可查看：

- **文档基本信息** — 文件名、类型、大小、上传时间
- **结构化内容** — 提取的标题、章节、关键信息
- **向量片段** — 生成的向量索引数量和片段预览

### 3.5 管理文档

- **搜索** — 通过关键词、文档类型、密级进行筛选
- **查看详情** — 点击文档名称查看完整信息
- **删除** — 点击删除按钮移除文档（同时删除 MinIO 中的文件）
- **分页浏览** — 使用底部分页器翻页

### 3.6 注意事项

- 单文件大小限制：**50 MB**
- 支持的文件格式：**PDF、DOCX、TXT**
- 解析时间因文档大小而异，通常数秒至数分钟
- 密级为「绝密」「机密」的文档需要对应权限才能查看

## 4. 多库管理操作指南

### 4.1 四大知识库

系统提供四个独立的知识库：

| 知识库 | 说明 | 用途 |
|--------|------|------|
| 📖 法规库 | 党纪法规、国家法律 | 审理依据查询 |
| 📁 资料库 | 政策文件、学习材料 | 参考资料查阅 |
| ⚖️ 裁判文书库 | 法院裁判文书 | 裁判标准参考 |
| 📋 案例库 | 典型案例、指导案例 | 类案比对分析 |

### 4.2 目录管理

#### 创建目录

1. 选择对应知识库（如「法规库」）
2. 在左侧目录树中点击 **「新增目录」**
3. 填写目录信息：
   - **目录名称** — 必填
   - **上级目录** — 选择父级目录（支持多级嵌套）
   - **密级** — 设置目录的保密级别
   - **权限范围** — 指定哪些角色可以访问
4. 点击 **「确认」**

#### 目录操作

- **展开/折叠** — 点击目录前的三角图标
- **编辑** — 右键菜单或工具栏编辑按钮
- **删除** — 删除空目录（含子目录的目录需先清空）
- **排序** — 通过拖拽或设置排序号调整顺序

### 4.3 文档管理

#### 新增文档

1. 在目标目录下点击 **「新增文档」**
2. 填写文档信息：
   - **标题** — 必填
   - **文号** — 如「中发〔2023〕xx号」
   - **发布单位** — 如「中共中央」
   - **发布日期** — 文档发布日期
   - **生效日期** — 法规生效日期
   - **效力状态** — 现行有效/已废止/已修订
   - **摘要** — 文档简要说明
   - **附件上传** — 上传文档文件（PDF/DOCX等）
3. 点击 **「保存」**

#### 文档检索

- **关键词搜索** — 在搜索框输入关键词
- **高级筛选** — 按发布单位、效力状态、密级等条件筛选
- **语义检索** — 输入自然语言描述，系统自动匹配相关文档

#### 文档操作

- **查看** — 点击文档标题查看详情和附件
- **编辑** — 修改文档信息
- **下载** — 下载附件文件
- **删除** — 移除文档（需确认）

### 4.4 密级控制

- 不同密级的文档仅对具有相应权限的用户可见
- 密级从高到低：绝密 > 机密 > 秘密 > 内部 > 公开
- 高密级用户可查看低密级文档，反之不可

## 5. 用户/角色/权限配置指南

### 5.1 权限模型概述

系统采用 **RBAC（基于角色的访问控制）** 模型：

```
用户 ──N:M── 角色 ──N:M── 菜单/权限
```

- 一个用户可以拥有多个角色
- 一个角色可以分配给多个用户
- 一个角色可以拥有多个菜单和按钮权限
- 用户的最终权限 = 所有角色权限的并集

### 5.2 部门管理

#### 创建部门

1. 进入 **「系统管理 > 部门管理」**
2. 点击 **「新增」**
3. 填写部门信息：
   - **上级部门** — 选择父级部门
   - **部门名称** — 必填
   - **负责人** — 部门负责人姓名
   - **联系电话** — 部门联系方式
   - **排序** — 显示顺序
   - **状态** — 启用/停用
4. 点击 **「确定」**

#### 部门树操作

- **拖拽排序** — 直接拖拽调整部门层级
- **批量操作** — 勾选多个部门进行批量启用/停用

### 5.3 角色管理

#### 创建角色

1. 进入 **「系统管理 > 角色管理」**
2. 点击 **「新增」**
3. 填写角色信息：
   - **角色名称** — 如「审理人员」
   - **角色编码** — 如「trial_staff」（唯一标识）
   - **描述** — 角色说明
   - **状态** — 启用/停用
4. 点击 **「确定」**

#### 分配权限

1. 在角色列表中点击 **「分配权限」**
2. 在弹出的权限树中勾选需要的菜单和按钮
3. 点击 **「保存」**

> 💡 **提示**：权限树包含三种类型：
> - 📁 目录 — 左侧导航菜单分组
> - 📄 菜单 — 具体功能页面
> - 🔘 按钮 — 页面内的操作按钮（新增、编辑、删除等）

### 5.4 用户管理

#### 创建用户

1. 进入 **「系统管理 > 用户管理」**
2. 点击 **「新增」**
3. 填写用户信息：
   - **用户名** — 登录账号（唯一）
   - **密码** — 初始密码
   - **真实姓名** — 必填
   - **所属部门** — 选择部门
   - **手机号** — 联系方式
   - **邮箱** — 电子邮箱
   - **角色** — 勾选一个或多个角色
   - **状态** — 启用/停用
4. 点击 **「确定」**

#### 用户操作

| 操作 | 说明 |
|------|------|
| 编辑 | 修改用户基本信息和角色 |
| 重置密码 | 将密码重置为默认值 |
| 删除 | 移除用户（同时解除角色关联） |
| 启用/停用 | 控制用户登录权限 |

### 5.5 菜单管理

#### 菜单类型

| 类型 | 说明 | 示例 |
|------|------|------|
| 目录 | 导航分组，不可直接访问 | 「系统管理」 |
| 菜单 | 具体功能页面 | 「用户管理」 |
| 按钮 | 页面内的操作权限 | 「新增用户」按钮 |

#### 创建菜单

1. 进入 **「系统管理 > 菜单管理」**
2. 点击 **「新增」**
3. 根据类型填写对应信息：
   - **上级菜单** — 选择父级
   - **菜单名称** — 必填
   - **路由路径** — 前端路由（如 `user`）
   - **组件路径** — Vue 组件路径（如 `system/user/index`）
   - **权限标识** — 如 `system:user:list`
   - **图标** — Element Plus 图标名
   - **排序** — 显示顺序
4. 点击 **「确定」**

### 5.6 权限配置最佳实践

1. **最小权限原则** — 仅授予用户完成工作所需的最小权限
2. **角色分组** — 按岗位创建角色，而非按个人
3. **定期审计** — 定期检查用户权限是否与实际岗位匹配
4. **密码策略** — 要求强密码，定期更换
5. **操作审计** — 通过审计日志追踪敏感操作

## 6. 常见问题 FAQ

### Q1: 忘记密码怎么办？

**A**: 请联系系统管理员，在 **「系统管理 > 用户管理」** 中找到您的账号，点击 **「重置密码」**。重置后的默认密码为 `123456`，登录后请立即修改。

### Q2: 为什么我看不到某些菜单？

**A**: 菜单的可见性由角色权限控制。请确认：
1. 您的角色是否包含该菜单的权限
2. 菜单状态是否为「启用」
3. 菜单可见性是否为「显示」

如需新增权限，请联系系统管理员分配。

### Q3: 文档上传失败怎么办？

**A**: 请检查以下几点：
1. 文件格式是否为 PDF/DOCX/TXT
2. 文件大小是否超过 50 MB 限制
3. MinIO 服务是否正常运行
4. 网络连接是否正常

如问题持续，请查看浏览器控制台错误信息并联系技术支持。

### Q4: 文档解析一直处于「处理中」状态？

**A**: 大文档解析可能需要较长时间（数分钟）。如果超过 30 分钟仍未完成：
1. 刷新页面查看最新状态
2. 检查后端服务日志
3. 如果状态变为「失败」，查看错误信息并重新上传

### Q5: 如何导出审计日志？

**A**: 进入 **「审计日志」** 页面，设置筛选条件后，点击 **「导出」** 按钮，系统将生成 Excel 文件供下载。

### Q6: 密级文档无法查看？

**A**: 请确认您的角色权限范围是否包含该文档的密级。例如：
- 只有「绝密」权限角色可查看绝密文档
- 「内部」权限角色可查看内部和公开文档

如需调整权限，请联系系统管理员。

### Q7: 如何进行类案检索？

**A**: （此功能开发中）进入 **「类案推送」** 模块，输入案件描述或上传案件文档，系统将自动匹配相似度最高的案例并返回结果。

### Q8: 系统响应很慢怎么办？

**A**: 请尝试以下操作：
1. 清除浏览器缓存
2. 检查网络连接
3. 关闭不需要的浏览器标签页
4. 如问题持续，请联系系统管理员检查服务器状态

### Q9: 如何修改个人信息？

**A**: 点击页面右上角的用户头像，选择 **「个人中心」**，可以修改：
- 真实姓名
- 手机号
- 邮箱
- 密码

### Q10: 数据安全如何保障？

**A**: 系统采取以下安全措施：
- 🔐 密码使用 BCrypt 加密存储
- 🔐 传输层使用 HTTPS 加密
- 🔐 操作日志全量审计
- 🔐 密级分级访问控制
- 🔐 数据库定期备份
